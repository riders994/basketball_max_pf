# Prompt Log — raw capture

Append-only, **machine-written** by the `UserPromptSubmit` hook
(`scripts/log_prompt.py`). Every submitted prompt is recorded here verbatim with
a timestamp, so the source material is never lost.

This is the raw feed. The curated, annotated narrative — with response notes and
decisions — lives in [`PROMPT_LOG.md`](PROMPT_LOG.md). Entries below this header
are added automatically; don't edit them by hand.
